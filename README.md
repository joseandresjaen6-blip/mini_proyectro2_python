# Unidad 7: Recursividad en Python

## Descripción del proyecto

Este proyecto consiste en la realización de cinco ejercicios prácticos sobre el tema de la **recursividad en Python**, con el objetivo de comprender cómo una función puede llamarse a sí misma para resolver un problema de manera progresiva.

## Objetivos

- Comprender el concepto de recursividad.
- Identificar el caso base y el caso recursivo.
- Implementar funciones recursivas en Python.
- Practicar la resolución de problemas mediante llamadas recursivas.

## Ejercicios realizados

**1. Cuenta regresiva (Countdown)**

Se implementó una función que cuenta desde un número indicado hasta cero. Al llegar a cero, muestra el mensaje "¡Despegue!".

**2. Invertir una cadena**

Se creó una función recursiva que invierte el orden de los caracteres de una cadena de texto.

**3. Calcular una potencia**

Se desarrolló una función que calcula un número elevado a un exponente mediante multiplicaciones recursivas.

**4. Verificar palíndromos**

Se implementó una función que comprueba si una palabra se lee igual de izquierda a derecha y de derecha a izquierda.

**5. Encontrar el número máximo de una lista**

Se desarrolló una función que compara los elementos de una lista recursivamente para encontrar el número mayor.

## Tecnologías utilizadas

- **Lenguaje de programación:** Python.
- **Control de versiones:** Git.
- **Repositorio remoto:** GitHub.

## Conclusión

La realización de estos ejercicios permitió practicar el uso de la recursividad y comprender la importancia del caso base para detener las llamadas de una función. También se reforzó la lógica de programación mediante la solución de problemas relacionados con números, cadenas de texto y listas.

Este proyecto forma parte de las actividades prácticas de la Unidad 7: Recursividad.
